Wie wird das gemacht?

In der Dokumentation geht es nicht darum, wer etwas tut, sondern was passiert. Genau dafür gibt es das Passiv: Der Code wird getestet.

≈ 15 Min Fokus: Passiv (werden + Partizip II) Rückruf · 1 Geschichte · 5 Wörter · sprechen · 5–8 Sätze schreiben

2 Die Geschichte

Hör zu und lies laut mit. Die rot markierten Blöcke sind Passiv — schau auf werden + Partizip II.

Der Ablauf im Team

Bei uns wird jeder Schritt dokumentiert. Eine neue Funktion wird zuerst von den Entwicklern geschrieben. Danach wird der Code getestet. Wenn alles funktioniert, wird die Änderung freigegeben. Die Freigabe wird im System gespeichert. Erst dann wird die neue Version veröffentlicht. Die Nutzer werden über die Änderung informiert. Fehler werden sofort gemeldet und behoben. Am Ende wird das Ergebnis im Protokoll festgehalten. So wird die Qualität gesichert. Manche Schritte werden automatisch gemacht, andere müssen manuell geprüft werden. Der ganze Ablauf wird jedes Mal wiederholt.

Das eine Muster

Passiv = werden + Partizip II am Ende. Die Person ist unwichtig oder unbekannt.

  • Präsens: Der Code wird getestet.
  • Vergangenheit: Der Code wurde getestet.
  • Mit Modalverb: Der Code muss getestet werden.
  • Wer es tut: von den Entwicklern (von + Dativ).

Nicht verwechseln: Der Code wird getestet. (Vorgang) vs. Der Code ist getestet. (Zustand). Tabelle: Kurzreferenz.

5 Deine Prozess-Doku

Szenario

Beschreib den Ablauf in deinem Team, wenn eine neue Änderung fertig ist: Was wird zuerst gemacht? Was wird geprüft? Wer oder was gibt die Freigabe? Was passiert danach?

Schreib überwiegend im Passiv (wird getestet, wird veröffentlicht). Verwende mindestens einen Satz mit Modalverb (muss geprüft werden) und einen Satz mit von + Dativ (von den Entwicklern). Beende die Doku mit einem Zustandspassiv (Am Ende ist alles getestet.). Nutze außerdem zwei neue Wörter aus Teil 3.

Ich gebe dir Feedback mit Fehlertyp, Korrektur und Regel. Schreib nicht ab: Beschreibe deinen eigenen Ablauf.

Primärquelle: Lingolia — Passive Voice. Zeigt das Vorgangspassiv in allen Zeiten, das Modalpassiv und von vs. durch.
